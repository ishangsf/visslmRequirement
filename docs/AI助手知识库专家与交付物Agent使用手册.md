# AI 助手：知识库专家与交付物 Agent 使用手册

> 本手册按当前版本的 VISSLM AI 助手界面与行为编写，只说明已实现的功能。

## 1. 开始前

1. 打开“AI 助手”页面，确认顶部状态为“模型可用”。模型未连接时，先点击“配置”完成模型设置。
2. 使用知识库专家前，先在“资产中心 → 知识库”上传文档并等待索引完成。当前支持 DOCX、PDF、XLSX/XLS、TXT，单文件不超过 100 MB。
3. 在输入框中点击“选择专家”，或直接输入 `@`，再从候选菜单选择专家。也可以直接输入完整的 `@知识库专家` 或 `@交付物专家`。

## 2. 使用 `@知识库专家`

### 典型流程

1. 在 AI 助手输入框选择“知识库专家”。
2. 在名称后输入问题，例如：

   ```text
   @知识库专家 查找技术协议中关于数据脱敏的要求
   ```

3. 按 Enter 发送，等待检索和回答完成。
4. 在回答下方查看“证据区”和“回答依据”。来源会标记为“知识文档”；点击来源可打开对应的知识库文档详情。

### 能力边界

- 知识库专家只检索已上传并完成索引的知识库文档分块，只使用文档证据生成回答。
- 它不会把数据中心记录当作知识库事实，也不会替用户查询或修改数据中心记录。
- 文档没有可核验证据、索引尚未就绪或没有匹配内容时，系统会说明原因并停止生成猜测性回答。

## 3. 使用 `@交付物专家`

交付物专家只整理已完成回答中的 EvidenceBlock、数据视图和来源定位，不重新检索、不重新执行查询。

### 典型流程

1. 先在当前会话中完成一条带“证据区”的成功回答。失败、已停止或没有 EvidenceBlock 的回答不能作为交付物来源。
2. 发送交付物请求，例如：

   ```text
   @交付物专家 将上一条回答整理成汇报材料
   ```

   系统会自动取当前会话中最近一条“已完成且含 EvidenceBlock”的助手回答作为来源。若来源不符合条件，会提示先选择一条有可核验证据的已完成回答。
3. 在“生成交付物”预览面板检查标题、摘要、目标文件、证据数量、数据行数以及记录/文档依据数量。确认内容和影响范围后选择格式。
4. 点击“确认生成”。系统会再次校验证据并保存本地交付物版本，随后弹出“导出 AI 交付物”保存对话框。
5. 在保存对话框中选择文件名和位置并保存；成功后会显示已导出的文件名。

回答下方若出现“基于已验证证据创建”区域，也可以从“文件交付草稿”入口打开同一类受控预览。

### 四种格式

| 格式 | 面板用途 | 适合场景 |
| --- | --- | --- |
| DOCX（报告） | 结构化文字报告 | 阅读、审阅和正式报告交付 |
| XLSX（表格） | 证据与数据明细 | 筛选、核对和后续表格处理 |
| PPTX（演示） | 汇报型演示文稿 | 会议汇报和演示讲解 |
| ZIP（导出包） | 报告、表格、演示文稿及清单的组合包 | 一次性归档或交付全部材料 |

导出内容是本次回答携带的已验证快照，不会因导出再次访问数据中心或知识库；数据视图如果只是回答中的预览，导出也会按该快照和已声明数量呈现。

## 4. 状态、取消与失败

- **准备预览**：正在构建交付物预览；预览完成后才能确认生成。
- **正在生成**：文件生成和校验进行中，操作按钮会暂时禁用，请等待完成。
- **已生成**：文件已保存到用户在保存对话框选定的位置。
- **生成失败**：界面显示失败原因。系统会撤销本次已经保存的交付物记录，再修正来源或格式后重试。
- **预览阶段取消**：点击“取消”或关闭预览，不会生成文件，也不会写入交付物记录。
- **保存对话框取消**：点击保存对话框的取消按钮，会取消本次导出并撤销刚创建的本地交付物记录；原始数据不受影响。

交付物记录中的“撤销”只撤销本地交付物版本，不删除数据中心记录或知识库文档。已撤销的记录不能再次导出。

## 5. 历史记录与再次导出

1. 在 AI 助手左侧“历史会话”区域点击“交付物记录”。
2. 在“AI 交付物记录”中查看标题、类型、版本、状态和更新时间。
3. 对状态为“有效”的记录，在操作列直接点击 DOCX、XLSX、PPTX 或 ZIP，即可选择对应格式并再次打开保存对话框。
4. 记录状态为“已撤销”时不提供导出操作；如需清理仍有效的本地版本，可点击“撤销”。

再次导出已有记录只读取该记录的已保存快照，不修改原始数据。

## 6. 证据与安全边界

- “EvidenceBlock”是回答使用的结构化证据账本；生成交付物前必须至少有一个可核验 EvidenceBlock。
- 交付物预览会展示证据、数据行和来源数量，便于在确认前检查范围。
- 交付物专家不会写入数据中心或知识库；保存的只是本地交付物版本和导出的文件。
- 文件导出必须经过预览校验和用户确认。取消或失败时，本次新增的保存记录会撤销；这不会回滚或删除原始数据。

## 7. 故障排查

| 现象 | 处理方式 |
| --- | --- |
| “模型未连接” | 点击“配置”完成模型设置，返回 AI 助手确认状态变为“模型可用”。 |
| 知识库回答提示索引未就绪 | 到“资产中心 → 知识库”确认文档已上传且状态为“已就绪”；必要时重建索引。 |
| 知识库回答提示没有可核验证据 | 缩小问题范围、补充文档中的明确关键词，或确认文档确实已加入知识库。 |
| 交付物提示没有可核验 EvidenceBlock | 先完成一条成功且带“证据区”的回答，再发送 `@交付物专家`。 |
| 交付物来源不是想要的那一条 | 在当前会话中重新发送目标问题，使它成为最近一条成功且含证据的回答，再发起交付物请求。 |
| 保存对话框取消或文件生成失败 | 这是本次导出未完成的正常结果；检查磁盘位置和权限后，从有效历史记录重新导出。 |
| 历史记录显示“已撤销” | 该本地版本不可导出；重新基于有效回答生成，或使用其他仍为“有效”的记录。 |
