# VISSLM Agent v1.5.7

发布日期：2026-10-29。Windows x64 桌面版。

## 推送用户映射与固定参数

- 在「数据推送 → 推送配置」维护多组源登录名到内网登录名/能力名的映射，并指定需要转换的目标字段。
- 支持单用户、用户数组及逗号/分号/换行分隔的多用户值；只转换指定字段，不修改本地源数据。
- 未匹配用户默认阻止整批发送并提示记录与字段，也可选择保留原值。错误字段、重复映射和不完整配置会被拦截。
- 支持请求体及 URL 固定参数；请求体可使用文本或 JSON 值。固定请求体值覆盖同名字段，认证与新建位置参数受到保护。
- 配置自动保存，预览展示最终转换结果；新增配置表格支持列宽拖拽、键盘调整、刷新恢复和内部滚动，兼容深浅主题。

## 累计改进（自线上 v1.5.2）

- 图片采集与资源包处理覆盖嵌套字段和数组，按图片实际字节识别格式，改善跨平台图片迁移与缺图提示。
- AI 助手使用结构化语义计划、字段目录、范围与结果校验，改善记录分组、分析和执行状态反馈。
- 集成平台 MCP 分析及证据展示，完善可视化生成、数据快照和预览验证流程。
