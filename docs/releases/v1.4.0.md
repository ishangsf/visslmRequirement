# VISSLM Agent v1.4.0

## 主要更新

- 数据中心新增“数据维护”入口，支持全部历史数据或所选记录范围。
- 新增一键优化匹配、仅清理数据和仅重建索引三种维护操作。
- 增加启动前只读扫描预览、阶段进度、安全停止、失败项重试和任务状态持久化。
- 统一从原始 JSON 与字段标签重算规范化文本和业务匹配文本，清理过程不改写原始 JSON、不合并记录。
- 支持按记录事务性重建 BM25/FTS5 与向量索引；单条向量失败时保留原有可用索引，维护任务与其他索引任务互斥。
- 数据详情展示匹配准备度、清理版本、实际匹配文本、全文索引状态、向量模型、分块数量、更新时间和失败原因。

## 升级说明

升级后可在“资产中心”打开“数据维护”，先执行只读预览，再按范围启动维护。历史源数据 JSON 不会被修改；向量索引沿用当前本地 embedding 模型和存储方式。

## 验证

本版本沿用已完成的类型检查、生产构建、数据维护回归、需求匹配回归、知识库 smoke、项目管理 smoke 和资产中心 UI smoke 结果；本次发布流程不重复运行回归测试。
