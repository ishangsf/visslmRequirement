# VISSLM Agent v1.3.0

## 主要更新

- 重构需求分析专家匹配链路：全量 Dense 与 BM25 召回，经 RRF 合并、Cross-Encoder 精排和确定性评分后，对 Top 10 执行一次批量 AI 解释。
- 所有需求统一使用完整清洗原文参与匹配，不要求额外的预生成资产。
- 新增严格的匹配 UID、证据和解释结构校验。
- 优化 Ollama 流式响应、超时和输出预算处理，提高长文本回答的稳定性与可诊断性。
- 修复应用启动期间重复重建需求全文索引导致长时间无响应的问题；迁移改为版本化、幂等、事务化并带完整性检查。
- 增加 Electron 窗口显示兜底，避免渲染进程已启动但主窗口不可见。

## 验证

- TypeScript 类型检查和生产构建通过。
- 需求匹配契约、当前索引、正式匹配与 v2 回归通过。
- Ollama 流式响应、需求分析专家、相似度、字段定义和项目管理 smoke test 通过。
- Windows x64 NSIS 安装包完成生成和校验。

## 升级说明

安装后首次启动会校验需求业务索引完整性；索引已经完整时会直接复用，不再在每次启动时重复全量计算。
