# VISSLM Agent v1.5.2

- 修复采集结束清理旧数据时，历史需求匹配候选引用导致的外键冲突。相关引用与旧记录在同一事务内清理，失败时回滚。
- 采集失败详情展示失败阶段、任务、记录或批次上下文、原始原因和处理建议；本地处理错误也会保存到日志，任务异常不再误显示为单条记录失败。
- 图片缺失、未解析或上传失败时，继续创建记录，保留文字与成功上传的图片，失败图片使用“图片未能上传”占位。创建成功显示“已创建（部分图片未上传）”，图片警告与记录创建失败分别统计。
- 同一记录中能唯一对应本地图片的旧地址自动转换为资源引用，同一图片在本次记录推送中上传一次并复用；图片警告不会自动重试创建记录。

验证：类型检查、采集清理和回滚专项、缺图推送专项、手动删除回归、图片推送与上传鉴权、采集进度 UI 静态检查、项目管理 smoke、完整构建、安装包启动和资源校验。
